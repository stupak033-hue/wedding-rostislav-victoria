## Публикация
1. Загрузите **всё содержимое** этой папки в корень GitHub-репозитория.
2. Чтобы получить публичную ссылку прямо с GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
3. Чтобы анкеты гостей действительно приходили организаторам, подключите репозиторий к Netlify и опубликуйте его там: формы `rsvp` и `preferences` размечены для Netlify Forms. На GitHub Pages без отдельного серверного сервиса ответы могут сохраняться только локально в браузере гостя и не поступают организаторам.
